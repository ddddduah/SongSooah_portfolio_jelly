- `index.html` — 단일 정적 페이지. 빌드 과정 없음. 브라우저로 바로 열면 됨.
- 모든 이미지는 base64로 내장되어 있어 외부 에셋 없음. 폰트(Pretendard)만 CDN에서 로드.
- 원본 대비 변경: `<title>` → `송수아 | 경영기획 포트폴리오` (그 외 동일)
